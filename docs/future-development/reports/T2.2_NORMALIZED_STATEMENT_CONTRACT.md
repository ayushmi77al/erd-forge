## 1. Implementation Summary

1. **Normalized Statement & AST Contract (`apps/web/src/lineage/parser/SqlParserAdapter.ts`):**
   * **`NormalizedStatement`:** Unified statement abstraction supporting `SELECT`, `CREATE_TABLE`, `CREATE_VIEW`, `INSERT`, `UPDATE`, `DELETE`, and `OTHER`.
   * **`NormalizedSelectStatement`:** Models projections (`columns`), source items (`from`), filtering (`where`), grouping (`groupBy`), aggregations (`having`), window qualifiers (`qualify`), sorting (`orderBy`), and set operations (`setOperations`).
   * **`NormalizedColumn` & `NormalizedColumnRef`:** Decouples projection items, preserving column names, aliases, underlying AST expressions, wildcard/star markers, and direct source references (`table`, `column`, `context`).
   * **`NormalizedFromItem`:** Models base tables, nested subqueries, and table functions with comprehensive join metadata (`joinType`, `onCondition`, `usingColumns`).
   * **`NormalizedCTE`:** Supports scoped Common Table Expressions with explicit column alias mapping.
   * **`NormalizedSetOperation`:** First-class modeling of set operations (`UNION`, `UNION_ALL`, `INTERSECT`, `EXCEPT`).
   * **`SqlParserAdapter` Interface:** Standardized interface requiring `id`, `name`, `version`, `initialize()`, and `parse(sql, dialect)`.

2. **Typed Dialect Mapping:**
   * Implemented `mapToWasmDialect(dialect: SQLDialect): WasmDialect` mapping all ERD Forge warehouse dialects directly to native `@guanmingchiu/sqlparser-ts` dialect constants:
     - `mssql` &rarr; `mssql`
     - `postgresql` &rarr; `postgresql`
     - `mysql` &rarr; `mysql`
     - `sqlite` &rarr; `sqlite`
     - `oracle` &rarr; `oracle`
     - `bigquery` &rarr; `bigquery`
     - `redshift` &rarr; `redshift`
     - `snowflake` &rarr; `snowflake`
     - `databricks` &rarr; `databricks`
     - *Fallback:* `generic`

3. **AST Traversal & Factory Utilities:**
   * `createEmptyNormalizedStatement(type)` & `createEmptyNormalizedSelect()`
   * `isSelectStatement()` & `isDdlOrDml()` type guards
   * `collectAllFromTables()`: Recursively walks FROM clauses, JOINs, derived table subqueries, and set operation branches.
   * `collectAllSubqueries()`: Recursively traverses nested subquery trees.

4. **Automated Unit Testing (`apps/web/tests/lineage/SqlParserAdapter.test.ts`):**
   * Tested dialect mapping exhaustively across all 9 supported database engines.
   * Verified factory defaults and type guard branching.
   * Modeled a complex enterprise statement containing CTEs, window functions with QUALIFY clauses, inner joins, derived tables, and UNION_ALL set operations.
   * Verified recursive table and subquery extraction utilities.

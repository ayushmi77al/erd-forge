## 4. Dagre Layout Latency Benchmarks (Baseline)

Measured directly on the existing `calculateAutoLayout` implementation:

| Schema Complexity | Main-Thread Duration | UI Freeze Impact |
|:---|---:|:---|
| **50 Tables (Relational DAG)** | **131.70 ms** | Noticeable frame drop during auto-arrange |
| **500 Tables (Stress Test)** | **693.94 ms** | **Critical UI freeze (~700ms)**; blocks click/drag interactions |

> [!IMPORTANT]
> Because Dagre runs synchronously on the main thread, 500-table layout calculation locks the browser tab for over two-thirds of a second. Offloading to an **ELK Web Worker** (Track 1) will completely eliminate this UI freeze.

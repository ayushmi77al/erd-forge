## 1. Executive Summary

Task T4.3 successfully extracts the entire SQL Lineage engine, AST walkers, symbol resolution tables, dual-engine WASM/Legacy parsing adapters, shadow rollout comparator, and graph stitching logic into the standalone package:
- **`@erd-forge/lineage`** (`packages/lineage/`)

## 2. Package Implementation Breakdown

### 2.1 Package Architecture (`packages/lineage/src/`)
- **Types & Dialect Contracts (`types.ts`):**
  - `SQLDialect` (`"mysql" | "postgres" | "sqlite" | "snowflake" | "bigquery" | "tsql" | "mssql" | "duckdb" | "databricks" | "generic"`).
  - `ParserEngine` (`"wasm" | "legacy"`).
  - `ParseError`, `ParseLineageOptions`, `ParseLineageResult`.
- **Graph & Models (`models/`):**
  - `LineageNode.ts`: Table, CTE, View, and Subquery lineage nodes with typed columns and sources.
  - `LineageEdge.ts`: Column-level and table-level dependency edges with SQL context (`select`, `where`, `join`, `group_by`, `order_by`).
  - `LineageGraph.ts`: Full lineage DAG container with statement summaries and generation metadata.
- **Graph Operations (`graph/`):**
  - `PipelineStitcher.ts`: Multi-statement graph stitching and cross-query lineage propagation.
  - `ERDLinker.ts`: Schema linkage associating SQL lineage tables with physical ERD project tables.
- **Core Parser Infrastructure (`parser/`):**
  - `ASTWalker.ts`: Abstract syntax tree traversal across dialects.
  - `SymbolTable.ts`: Scoped symbol resolution for CTEs, subqueries, aliases, and table references.
  - `SqlParserAdapter.ts`: Legacy node-sql-parser AST normalization adapter.
  - `WasmSqlParserAdapter.ts`: High-performance `@guanmingchiu/sqlparser-ts` WASM adapter.
  - `WasmLineageBuilder.ts`: AST normalization to `LineageGraph` builder (`buildLineageFromNormalized`, `parseSQLLineageWasm`).
  - `sqlLineageParser.ts`: Legacy parser entrypoint with fallback support.
  - `ShadowRolloutComparator.ts`: Concurrent differential execution, topological diffing, and zero-downtime fallback.
- **Constants (`constants/sampleQueries.ts`):**
  - Standard dialect SQL fixtures for MSSQL, BigQuery, Snowflake, DuckDB, Databricks, PostgreSQL, and MySQL.

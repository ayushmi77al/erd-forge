| **Complete Storage Denial** | Both OPFS SAHPool and IndexedDB fail (e.g. strict enterprise lockdown or corrupt storage quota) | Strictly refuses volatile in-memory degradation; throws `Fatal Storage Failure` | Throws descriptive error, marks storage uninitialized, zero silent data loss | Passed ✅ |

| **Ungraceful Tab Crash / Freeze** | Primary tab stops heartbeat broadcasts without emitting `RELEASE_LEASE` | Watchdog timer (5,000 ms production / 100 ms test) detects heartbeat silence, claims orphaned lease, and promotes follower to leader | Follower automatically becomes leader; no deadlock; writes resume cleanly | Passed ✅ |

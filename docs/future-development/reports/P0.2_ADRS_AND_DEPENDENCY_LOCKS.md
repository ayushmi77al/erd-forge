## 2. Architecture Decision Records (ADRs) Created

Created [docs/ADRs/ADR-005-to-008.md](file:///c:/Users/ayush.mittal/Projects/erd-forge/docs/ADRs/ADR-005-to-008.md) following the repository's established convention:

* **ADR-005: Layout Engine — Eclipse Layout Kernel (ELK) in Web Worker**
  * Supersedes Dagre main-thread layout.
  * Mandates `elk-api` with dedicated Web Worker factory; establishes compound domain hierarchy, qualified `${schema}.${table}` node IDs, deterministic grid fallbacks for unlinked nodes, and `layoutEpoch` / `AbortController` cancellation.
* **ADR-006: SQL Lineage Parser — WASM Adapter (`@guanmingchiu/sqlparser-ts`)**
  * Supersedes `node-sql-parser` for core dialects.
  * Establishes `SqlParserAdapter` contract and `NormalizedStatement` AST schema. Retains `node-sql-parser` as a shadow/fallback until fixture parity passes.
* **ADR-007: Storage Layer — Official SQLite WASM with OPFS SAHPool**
  * Supersedes ADR-002 (`wa-sqlite`).
  * Adopts `opfs-sahpool` for headerless OPFS persistence. Enforces a dedicated Web Worker boundary via Comlink, durable `IndexedDBAdapter` fallback (never in-memory), and `BroadcastChannel` single-tab lease management.
* **ADR-008: Export Pipeline — Browser Canvas Hardening & OWASP CSV Sanitization**
  * Retains `html-to-image` for DOM `<foreignObject>` capture with 32KB chunked base64 font encoding.
  * Scopes SVG export explicitly to browser viewing/printing.
  * Implements OWASP CSV injection neutralization (`'`) for `=, +, -, @, \t, \r`.

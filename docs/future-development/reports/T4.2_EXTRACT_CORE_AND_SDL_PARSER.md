## 2. Package Implementation Breakdown

### 2.1 `@erd-forge/core`
- **Models (`packages/core/src/models/`):**
  - `Column.ts`, `Table.ts`, `Relationship.ts`, `Domain.ts`, `Tag.ts`, `Comment.ts`, `Sheet.ts`, `GlossaryTerm.ts`, `Project.ts`.
- **Commands (`packages/core/src/commands/`):**
  - `Command.ts`: Interface for state mutations on `ERDForgeProject`.
  - `CommandManager.ts`: Undo/redo history manager with configurable depth.
  - `AddTableCommand.ts`, `RemoveTableCommand.ts`, `AddColumnCommand.ts`: Core transactional commands.
- **Layout Contracts (`packages/core/src/layout/`):**
  - `LayoutTable`, `LayoutRef`, `LayoutOptions`, `NodePosition`, `LayoutMap`.

  - 9/9 tests green, 0 compiler errors.

### 2.2 `@erd-forge/parser-sdl`
- **Grammar & AST (`packages/parser-sdl/src/`):**
  - `ast.ts`: Complete TypeScript AST nodes (`SDLProgram`, `SDLTable`, `SDLColumn`, `SDLRef`, etc.).
  - `errors.ts`: Portable `SDLError` interface decoupled from frontend stores.
  - `grammar.pegjs`: Standard Peggy SDL grammar specification.
  - `grammar.js`: Precompiled ES module parser generated via Peggy.
- **Parser & Tools (`packages/parser-sdl/src/`):**
  - `SDLParser.ts`: Two-tier resilient parser with chunked statement boundary fallback.
  - `SDLSerializer.ts`: AST-to-SDL string serializer.
  - `SDLValidator.ts`: Semantic validation rules.
- **Package Tests (`packages/parser-sdl/tests/`):**
  - 14/14 tests green covering resilient recovery, options, indexes, views, top-level refs, and serializer.

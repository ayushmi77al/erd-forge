## 1. Implementation Summary

1. **Collision-Safe Node Identifiers:**
   * Updated `getTableKey(schema, name, id)` in `apps/web/src/core/layout/autoLayout.ts`.
   * Tables with identical names across distinct schemas (e.g. `public.users` vs `audit.users`) receive unique, non-colliding layout coordinates.
   * Preserved `table.name` map keys for single-schema backward compatibility with legacy consumers.
2. **Compound Domain Hierarchy:**
   * Grouped tables by `table.domain` into compound parent `ElkNode` structures (`domain:Finance`, `domain:Security`, etc.) with dedicated internal padding (`elk.padding: [top=50,left=40,bottom=40,right=40]`).
   * Implemented recursive coordinate aggregation so children inside compound domain nodes receive correct canvas-absolute coordinates.
3. **Measured Dimensions & Deterministic Grid Fallbacks:**
   * Integrated `table.measuredWidth` and `table.measuredHeight` from React Flow measurements, falling back to estimated column heights only when unmeasured.
   * Implemented deterministic multi-column grid placement for unlinked tables offset below the main diagram, replacing the legacy stacked `{ x: 80, y: 80 }` coordinates.
4. **Caller Modernization (`apps/web/src/components/canvas/ERDCanvas.tsx`):**
   * Replaced synchronous Dagre calls with asynchronous Promise resolution of `calculateAutoLayout`.
   * Added an automated layout effect on initial load and schema mutations.
   * Rewired `layoutEpoch` auto-arrange trigger to apply ELK positions smoothly with `fitView`.

## 1. Implementation Summary

1. **WASM Lineage Builder (`apps/web/src/lineage/parser/WasmLineageBuilder.ts`):**
   * Implemented `buildLineageFromNormalized(statements, rawSql, options)` and `parseSQLLineageWasm(sql, dialect, options)`.
   * Maps `NormalizedStatement` contracts into the canonical `LineageGraph` entity model (`LineageNode`, `LineageEdge`, `ColumnLineageMapping`, `SQLStatementSummary`).
   * **Scope & Alias Resolution:** Integrates `SymbolTable` to resolve multi-level CTE scopes, aliases, and nested subquery namespaces without phantom base table generation.
   * **Column-Level Lineage:** Maps direct projections (`isDirect: true, context: "select"`) and preserves indirect clause dependencies (`context: "where" | "join" | "group_by" | "order_by"`).
   * **Downstream Integration:** Automatically applies `PipelineStitcher.stitch()` for cross-statement flows and `ERDLinker.link()` for reconciliation with catalog ERD tables.
   * **Worker Thread Integration:** Exposed `parseSQLWasm` in `apps/web/src/workers/lineage.worker.ts` alongside existing Comlink endpoints.

2. **AST & Normalizer Enhancements (`apps/web/src/lineage/parser/WasmSqlParserAdapter.ts`):**
   * **`WITH ... INSERT INTO` Support:** Detected nested `Insert` bodies within top-level `Query` AST nodes (standard in PostgreSQL ETL scripts), correctly normalizing target tables and CTEs.
   * **`MERGE INTO` Statements:** Implemented full normalization for Databricks / Snowflake `MERGE INTO target USING source ON condition` with update/insert branching.
   * **`PIVOT` Table Wrappers:** Unwrapped `Pivot` and `Unpivot` table factors in `normalizeTableFactor`, extracting underlying physical tables and derived subqueries.

3. **Comprehensive Parity & Differential Test Suite (`apps/web/tests/lineage/differentialParity.test.ts`):**
   * **Legacy Suite Parity:**
     - Verified exact node type parity (`TABLE`, `CTE`, `SUBQUERY`, `FINAL_SELECT`), identical edge connections, and identical upstream/downstream flows on the existing `sqlLineageParser.test.ts` test queries.
     - Confirmed chained CTE resolution without duplicate base table collisions.
     - Confirmed column-level lineage and indirect clause dependency extraction.
     - Confirmed syntax error detection, line/column tracking, and null graph emission on malformed SQL.
   * **Gate 0 Fixture Corpus Differential Analysis:**
     - Evaluated all 7 fixtures from `apps/web/tests/fixtures/sql/sqlFixtures.ts` across PostgreSQL, Snowflake, BigQuery, Databricks, DuckDB, MySQL, and MSSQL.
     - **WASM Pass Rate: 7 / 7 (100.0%)**

## 1. Implementation Summary

1. **Cell Sanitization Function (`apps/web/src/lineage/utils/exportUtils.ts`):**
   * Implemented `sanitizeCsvCell(value: string | undefined): string`:
     - Handles `undefined`, `null`, and empty string inputs cleanly, returning `""`.
     - Detects formula trigger characters at the start of trimmed strings: `=`, `+`, `-`, `@`, `\t`, and `\r`.
     - Prepends a single quote (`'`) to neutralize spreadsheet formula evaluation (preventing DDE commands and payload execution in Excel/Google Sheets).
     - Standardizes RFC 4180 CSV compliance by doubling internal double quotes (`"` &rarr; `""`) and wrapping the resulting cell in quotes (`"..."`).

2. **Lineage CSV Export Integration:**
   * Updated `exportLineageToCsv` to map all generated rows through `sanitizeCsvCell(cell)`:
     - Target table / schema names
     - Target column names
     - Source table / schema names
     - Source column names
     - Transformation expressions
     - Lineage context / edge types

3. **Automated Unit Testing & Fixture Verification (`apps/web/tests/lineage/exportUtils.test.ts`):**
   * Imported and executed tests against `csvSecurityFixtures` defined in `apps/web/tests/fixtures/csv/csvFixtures.ts`.
   * Verified neutralizations for:
     - DDE Command Injection (`=cmd|' /C calc'!A0` &rarr; `"'=cmd|' /C calc'!A0"`)
     - Formula execution (`=SUM(1,2)` &rarr; `"'=SUM(1,2)"`)
     - Prefix operators (`+calc`, `-5*2`, `@HYPERLINK`)
     - Whitespace and control prefix triggers (`\t`, `\r`)
     - Normal alphanumeric strings preserved without leading single quote
   * Tested end-to-end blob creation in `exportLineageToCsv` with mocked DOM/URL endpoints (`URL.createObjectURL`, `URL.revokeObjectURL`, anchor click).

## 1. Implementation Summary

1. **Stack-Safe Chunked Base64 Conversion (`arrayBufferToBase64`):**
   * Implemented 32KB (`0x8000`) sliding window chunking.
   * Eliminates `RangeError: Maximum call stack size exceeded` that occurs when large font buffers (>65KB) are passed as spread arguments to `String.fromCharCode(...)`.
   * Verified bit-for-bit round-trip base64 decoding on buffers exceeding 120KB.

2. **Dynamic Base Path Font Resolution (`getEmbeddedFontCSS`):**
   * Uses `import.meta.env.BASE_URL` (configured as `/tools/erd-forge/app/`) to dynamically locate `/fonts/Inter-Variable.woff2`.
   * Fetches the font file at runtime, encodes it as an inlined base64 data URL, and constructs a clean `@font-face` block scoped to `.react-flow__node`.
   * Includes graceful error fallback to system sans-serif fonts in offline, headless, or test environments without throwing unhandled exceptions.

3. **HTML-to-Image Integration (`downloadImage`):**
   * Injects the generated `fontEmbedCSS` directly into the `html-to-image` `toPng` and `toSvg` options.
   * Retains canvas UI overlay filters (excluding minimap, controls, and panel elements).

4. **Unit Test Suite (`apps/web/tests/lineage/exportUtils.test.ts`):**
   * Authored 4 unit tests covering small buffer conversion, large 120KB+ buffer conversion, successful `@font-face` CSS generation, and network offline graceful degradation.
